# US-009 — Rachas Diarias (Streaks)

- **Epic:** Retención y Motivación
- **Prioridad:** Media (MVP)
- **Persona:** Santi (adolescente)
- **Estado:** Pendiente

## Descripción
Como **adolescente**, quiero **mantener una racha diaria de actividad** para **motivarme a volver cada día y no perder mi progreso**.

## Criterios de Aceptación
- [ ] La racha (`streak_count`) aumenta al completar actividad en días consecutivos.
- [ ] La racha se muestra de forma visible y motivadora en el dashboard.
- [ ] Si se rompe la racha, el mensaje es **motivador, no punitivo**.
- [ ] La racha alimenta la métrica de constancia del dashboard del padre (US-005).
- [ ] La lógica de racha tiene Unit Tests.

## Notas Técnicas
- Campo: `users.streak_count`.
- Mitigación de deserción (ver Riesgos del blueprint).

## Dependencias
- US-003 (registro de actividad diaria).
