# US-007 — Acceso Rápido del Adolescente (Alias + PIN)

- **Epic:** Autenticación y Onboarding
- **Prioridad:** Alta (MVP)
- **Persona:** Santi (adolescente)
- **Estado:** Pendiente

## Descripción
Como **adolescente**, quiero **acceder con mi alias y un PIN de 4 dígitos** para **entrar rápido a mi espacio sin depender del email del tutor**.

## Criterios de Aceptación
- [ ] El adolescente accede con **Alias + PIN de 4 dígitos**.
- [ ] El PIN se configura durante el onboarding.
- [ ] El acceso es rápido (pensado para uso frecuente en móvil).
- [ ] El PIN se almacena de forma segura (nunca en texto plano).
- [ ] El espacio del adolescente está separado lógicamente del acceso del tutor.

## Notas Técnicas
- Autenticación ligera basada en dispositivo, vinculada a la cuenta del tutor.
- Privacidad radical: el contenido tras el PIN no es accesible por el tutor.

## Dependencias
- US-013 (vinculación del perfil adolescente al tutor).
