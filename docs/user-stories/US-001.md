# US-001 — Perfil y Avatar Personalizado

- **Epic:** Identidad y Personalización
- **Prioridad:** Alta (MVP)
- **Persona:** Santi (adolescente)
- **Estado:** Pendiente

## Descripción
Como **adolescente**, quiero **elegir mi alias y configurar mi avatar** para **sentir que el espacio es privado, propio y personalizado**.

## Criterios de Aceptación
- [ ] El usuario puede introducir un **alias** (no requiere nombre real).
- [ ] El usuario puede seleccionar un **avatar base** entre varias opciones ilustradas.
- [ ] El alias y avatar se guardan en la tabla `users` (`alias`, `avatar_state`).
- [ ] El perfil es accesible y editable desde la pestaña **Perfil**.
- [ ] En ningún momento se solicita información personal identificable (privacidad radical).
- [ ] Los cambios persisten localmente (Zustand) y sincronizan con Supabase.

## Notas Técnicas
- Tablas: `users` (id, alias, avatar_state, level, xp, streak_count).
- Estado: Zustand con persisted storage.

## Dependencias
- US-007 (acceso del adolescente mediante Alias + PIN).
