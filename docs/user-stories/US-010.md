# US-010 — Evolución Visual del Avatar

- **Epic:** Retención y Motivación
- **Prioridad:** Media (MVP)
- **Persona:** Santi (adolescente)
- **Estado:** Pendiente

## Descripción
Como **adolescente**, quiero **que mi avatar evolucione (poses/accesorios) según mi nivel de XP** para **ver reflejado mi progreso y sentir orgullo por mi crecimiento**.

## Criterios de Aceptación
- [ ] El avatar cambia de **pose/accesorios** al subir de nivel.
- [ ] El estado del avatar se guarda en `users.avatar_state`.
- [ ] Los cambios de avatar se muestran con una animación/celebración.
- [ ] La evolución es coherente con la ganancia de XP (US-003).
- [ ] El estilo es ilustrado, energético y moderno (look "videojuego").

## Notas Técnicas
- Campo: `users.avatar_state`, `users.level`, `users.xp`.
- Assets en `/assets` (ilustraciones de avatares).

## Dependencias
- US-001 (avatar base), US-003 (XP).
