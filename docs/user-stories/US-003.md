# US-003 — Entrenamiento Interactivo y XP

- **Epic:** Entrenamiento de Funciones Ejecutivas
- **Prioridad:** Alta (MVP)
- **Persona:** Santi (adolescente)
- **Estado:** Pendiente

## Descripción
Como **adolescente**, quiero **realizar un ejercicio interactivo de menos de 5 minutos** para **ganar XP, subir de nivel y sentir que estoy progresando**.

## Criterios de Aceptación
- [ ] El dashboard muestra el **"Ejercicio del día"** como acción heroica principal.
- [ ] El ejercicio sugerido se selecciona según el perfil FE del usuario (`GET /exercises/daily`).
- [ ] Cada ejercicio se completa en **menos de 5 minutos**.
- [ ] Al finalizar, se registra en `daily_logs` y se asignan puntos de **XP** (`POST /progress/complete`).
- [ ] El usuario ve una **animación de éxito** (LottieFiles) al completar.
- [ ] El MVP incluye **15 ejercicios interactivos** (3 por cada FE).
- [ ] El nivel del usuario sube automáticamente al alcanzar el umbral de XP.

## Notas Técnicas
- Tablas: `daily_logs` (id, user_id, exercise_id, completed, timestamp).
- Endpoints: `GET /exercises/daily`, `POST /progress/complete`.
- Lógica de cálculo de XP/niveles debe tener Unit Tests.

## Dependencias
- US-002 (perfil FE diagnosticado).
