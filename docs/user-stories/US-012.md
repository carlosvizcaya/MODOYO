# US-012 — Modo Offline y Sincronización

- **Epic:** Infraestructura y Rendimiento
- **Prioridad:** Media (MVP)
- **Persona:** Santi (adolescente)
- **Estado:** Pendiente

## Descripción
Como **adolescente**, quiero **usar la app y guardar mi progreso sin conexión** para **entrenar en cualquier momento y que mis avances no se pierdan**.

## Criterios de Aceptación
- [ ] El progreso diario se guarda **localmente** (Zustand persisted storage).
- [ ] Al detectar conexión, los datos se **sincronizan con Supabase** automáticamente.
- [ ] No se pierden registros de `daily_logs` ni XP por falta de conexión.
- [ ] La sincronización resuelve conflictos de forma segura.
- [ ] El tiempo de carga se mantiene **< 2 segundos**.

## Notas Técnicas
- Estado: Zustand con persisted storage.
- Backend: Supabase (sincronización al reconectar).

## Dependencias
- US-003 (registro de actividad).
