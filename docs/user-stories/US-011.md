# US-011 — Notificaciones Respetuosas y Configurables

- **Epic:** Retención y Motivación
- **Prioridad:** Media (MVP)
- **Persona:** Santi (adolescente)
- **Estado:** Pendiente

## Descripción
Como **adolescente**, quiero **controlar la frecuencia y el tono de las notificaciones** para **recibir recordatorios motivadores sin sentirme vigilado o presionado**.

## Criterios de Aceptación
- [ ] Las notificaciones tienen **frecuencia baja** por defecto.
- [ ] El tono es **motivador**, nunca culpabilizador.
- [ ] El usuario puede **configurar o desactivar** las notificaciones.
- [ ] Se implementan vía **Expo Notifications**.
- [ ] No se envían notificaciones que revelen contenido privado.

## Notas Técnicas
- Integración: Expo Notifications (push).
- Preferencias persistidas en el perfil del usuario.

## Dependencias
- US-001 (perfil creado).
