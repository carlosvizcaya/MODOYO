# MODO YO

> Aplicación móvil multiplataforma de bienestar personal con IA integrada.

## Estructura del Proyecto

- `docs/blueprint.md` — Blueprint completo del proyecto (20 secciones)
- `docs/SDLC.md` — Marco de trabajo de desarrollo
- `docs/user-stories/` — Historias de usuario (IDs: US-001, US-002, ...)
- `docs/decisions/` — Registro de decisiones de arquitectura (ADRs)

## Instrucción para Agentes

Siempre que inicies un nuevo chat sobre este proyecto, lee el archivo `docs/blueprint.md` para recuperar el contexto completo del proyecto.

## Stack Tecnológico

- **Frontend:** React Native + Expo
- **Backend:** Node.js + NestJS
- **Base de datos:** PostgreSQL + Redis
- **IA:** OpenAI API (configurable)
- **Infraestructura:** AWS / configurable
