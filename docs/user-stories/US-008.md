# US-008 — Flujo de Onboarding y Creación de Avatar

- **Epic:** Autenticación y Onboarding
- **Prioridad:** Alta (MVP)
- **Persona:** Santi (adolescente)
- **Estado:** Pendiente

## Descripción
Como **adolescente**, quiero **un flujo de bienvenida guiado (test → avatar → tutorial)** para **entender la app rápidamente y sentir que empiezo una aventura, no una terapia**.

## Criterios de Aceptación
- [ ] El flujo sigue el orden: **Bienvenida → Test de Inicio → Creación de Avatar → Tutorial Rápido → Dashboard Principal**.
- [ ] El tutorial es breve y con tono lúdico ("videojuego de productividad").
- [ ] Al terminar, el usuario llega al Dashboard con el "Ejercicio del día" visible.
- [ ] El onboarding se puede completar sin fricción en menos de 10 minutos.
- [ ] No se usa lenguaje clínico ni de "tarea escolar".

## Notas Técnicas
- Endpoint: `POST /user/onboarding`.
- Integra US-001 (avatar) y US-002 (diagnóstico).

## Dependencias
- US-001, US-002, US-007.
