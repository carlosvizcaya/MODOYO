# US-005 — Dashboard del Facilitador (Métricas de Esfuerzo)

- **Epic:** Panel del Facilitador
- **Prioridad:** Alta (MVP)
- **Persona:** Padre/Tutor (Facilitador)
- **Estado:** Pendiente

## Descripción
Como **padre/tutor**, quiero **ver si mi hijo completó su racha diaria y su nivel de esfuerzo** para **validar su compromiso sin invadir su privacidad**.

## Criterios de Aceptación
- [ ] El dashboard muestra **métricas de constancia**: racha diaria, ejercicios completados, nivel actual.
- [ ] El facilitador **NUNCA** ve el contenido privado (metas, respuestas personales, resultados detallados del diagnóstico).
- [ ] Los datos se muestran de forma agregada (esfuerzo/constancia, no rendimiento clínico).
- [ ] El acceso al dashboard requiere autenticación del tutor (US-006).
- [ ] El tono del panel refuerza el rol de "arquitecto del contexto", no de "vigilante".

## Notas Técnicas
- Fuente de datos: `daily_logs` (agregado), `users.streak_count`, `users.level`.
- Barrera de privacidad estricta a nivel de API (no exponer `user_goals` ni respuestas).

## Dependencias
- US-006 (autenticación del tutor).
- US-003 (registro de actividad).
