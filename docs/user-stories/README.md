# User Stories — MODO YO

Historias de usuario del proyecto MODO YO, con IDs únicos según el formato definido en `docs/SDLC.md` (`US-XXX`).

Cada ficha incluye: Epic, Prioridad, Persona, Descripción (formato "Como... quiero... para..."), Criterios de Aceptación, Notas Técnicas y Dependencias.

## Convención de Estados
- **Pendiente** — no iniciada

- **En revisión** — en QA/testing
