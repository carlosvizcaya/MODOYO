# US-006 — Registro y Autenticación del Tutor

- **Epic:** Autenticación y Onboarding
- **Prioridad:** Alta (MVP)
- **Persona:** Padre/Tutor (Facilitador)
- **Estado:** Pendiente

## Descripción
Como **padre/tutor**, quiero **registrarme con email y contraseña** para **crear la cuenta, proveer la herramienta y acceder al dashboard de forma segura**.

## Criterios de Aceptación
- [ ] El tutor puede registrarse con **email y contraseña** (`POST /auth/register_tutor`).
- [ ] Se valida el formato del email.
- [ ] La contraseña debe tener al menos **8 caracteres**.
- [ ] Se muestra un mensaje de éxito al completar el registro.
- [ ] La autenticación usa **Supabase Auth**.
- [ ] Tras el registro, el tutor puede iniciar el onboarding del perfil adolescente (US-013).

## Notas Técnicas
- Backend: Supabase Auth (Email/Password).
- Endpoint: `POST /auth/register_tutor`.

## Dependencias
- Ninguna (punto de entrada del sistema).
