# US-004 — Muro de Victorias (Mis Metas)

- **Epic:** Metas y Logros Personales
- **Prioridad:** Alta (MVP)
- **Persona:** Santi (adolescente)
- **Estado:** Pendiente

## Descripción
Como **adolescente**, quiero **definir metas propias (ej. "llegar a la hora")** para **sentir satisfacción y poder personal al cumplirlas**.

## Criterios de Aceptación
- [ ] El usuario puede **crear metas personales** con un título libre.
- [ ] Cada meta tiene un estado: `pending` o `achieved`.
- [ ] El usuario puede **marcar una meta como lograda** y verla en su "Muro de Victorias".
- [ ] Las metas se guardan en `user_goals`.
- [ ] Al lograr una meta, se muestra un refuerzo positivo visual.
- [ ] Las metas son **100% privadas** (no visibles para el facilitador).

## Notas Técnicas
- Tabla: `user_goals` (id, user_id, title, status).
- Privacidad radical: el contenido de las metas nunca se expone al dashboard del padre.
