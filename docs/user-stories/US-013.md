# US-013 — Vinculación del Perfil Adolescente al Tutor

- **Epic:** Autenticación y Onboarding
- **Prioridad:** Alta (MVP)
- **Persona:** Padre/Tutor (Facilitador)
- **Estado:** Pendiente

## Descripción
Como **padre/tutor**, quiero **crear y vincular el perfil de mi hijo a mi cuenta** para **proveerle la herramienta manteniendo la separación de privacidad**.

## Criterios de Aceptación
- [ ] Tras registrarse (US-006), el tutor puede **crear el perfil adolescente** (`POST /user/onboarding`).
- [ ] El perfil adolescente queda **vinculado** a la cuenta del tutor.
- [ ] El tutor configura el acceso inicial (Alias + PIN, US-007) junto al adolescente.
- [ ] El tutor **no obtiene acceso** al contenido privado del adolescente tras la vinculación.
- [ ] Se soporta la relación 1 tutor → 1+ perfiles adolescentes.

## Notas Técnicas
- Endpoint: `POST /user/onboarding`.
- Relación de datos: `users.tutor_id` (o tabla de vínculo) — definir en el esquema.

## Dependencias
- US-006 (tutor registrado).
