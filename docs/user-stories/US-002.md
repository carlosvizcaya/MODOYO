# US-002 — Diagnóstico EFEF y Mapa de Poder

- **Epic:** Diagnóstico Inicial
- **Prioridad:** Alta (MVP)
- **Persona:** Santi (adolescente)
- **Estado:** Pendiente

## Descripción
Como **adolescente**, quiero **realizar una evaluación rápida y ver mi "Mapa de Poder" (Funciones Ejecutivas)** para **identificar mis talentos naturales sin sentir que es un test clínico**.

## Criterios de Aceptación
- [ ] El diagnóstico EFEF evalúa las **5 Funciones Ejecutivas**: control inhibitorio, autorregulación, memoria de trabajo, flexibilidad cognitiva y planificación.
- [ ] La evaluación se completa en **menos de 5 minutos**.
- [ ] Los resultados se muestran como un **"Mapa de Poder"** visual (no como diagnóstico clínico).
- [ ] El lenguaje enfatiza **talentos y fortalezas**, nunca déficits.
- [ ] Los puntajes se guardan en `executive_functions_scores`.
- [ ] El mapa es re-consultable desde el perfil.

## Notas Técnicas
- Tabla: `executive_functions_scores` (user_id, fc_inhibit, fc_auto, fc_workmem, fc_flex, fc_plan).
- El resultado alimenta el motor de recomendación de ejercicios (US-003).
